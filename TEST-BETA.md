# Test bêta · 1 semaine avec 3 à 5 vraies clientes sur iPhone

Le but : voir où une cliente pressée hésite, se trompe ou abandonne, avant d'ouvrir le studio à tout le monde. Une semaine suffit.

## Qui choisir
- **3 à 5 personnes**, pas plus : assez pour voir les vrais problèmes, assez peu pour les suivre de près.
- Un mélange : 2 ou 3 **marques** (commerce, restaurant, service) et 1 ou 2 **créatrices**.
- Au moins une personne **peu à l'aise avec la technologie**, et au moins une cliente **mexicaine** (espagnol) ou **américaine** (anglais).
- Des personnes qui vous diront franchement ce qui ne va pas. Offrez-leur le premier mois.
- Toutes sur **iPhone** (c'est là que la plupart publieront), une ou deux aussi sur ordinateur.

## Avant de commencer (côté agence)
- Créer leur espace, régler leur pays, préparer au moins **un type de visuel** et **un style vidéo** pour chacune.
- Agence › Fonctions visibles : laisser « Opportunités » et « Versions à tester » masquées, sauf si vous voulez les tester avec une créatrice précise.
- Leur envoyer le lien et une seule phrase : « Connectez-vous avec votre e-mail, puis suivez “Vos premiers pas”. Écrivez-moi dans le studio si quelque chose bloque. »
- Ne pas leur expliquer le studio à l'avance : on veut voir si elles comprennent seules.

## Ce qu'on leur demande, jour par jour
| Jour | À faire (10 minutes maximum) |
| --- | --- |
| 1 | Se connecter, suivre « Vos premiers pas », ajouter un produit (ou un sujet) avec 2 photos. |
| 2 | Créer un visuel avec un modèle, le télécharger, l'ajouter au calendrier. |
| 3 | Ouvrir les idées de vidéos, filmer une idée simple, l'envoyer et obtenir la vidéo finale. |
| 4 | Ouvrir le calendrier, copier le texte d'un post, le publier sur Instagram, cliquer sur « J'ai publié ce post ». |
| 5 | Écrire un message à l'agence dans le studio (une vraie question). |
| 6 | Libre : utiliser le studio comme elles le feraient normalement. |
| 7 | Répondre au court questionnaire ci-dessous (5 minutes). |

## Ce qu'on observe (côté agence)
- **Où elles bloquent** : messages dans le chat, demandes de rendez-vous, étapes du guide non cochées après 2 jours.
- **Erreurs** : alertes Sentry (si configuré), messages d'erreur qu'elles vous envoient en capture d'écran.
- **Temps** : combien de jours pour publier un premier contenu venu du studio.
- **Mots** : les mots qu'elles utilisent pour décrire les choses (« je n'ai pas trouvé… »). Si elles n'emploient pas les mots du studio, c'est un indice.
- Idéalement, **un appel de 15 minutes** avec une ou deux d'entre elles : regardez-les utiliser le studio en partage d'écran sans les aider.

## Le questionnaire de fin (5 questions)
1. Sur 10, à quel point le studio a-t-il été facile à utiliser ?
2. À quel moment avez-vous hésité ou été bloquée ?
3. Qu'avez-vous publié grâce au studio cette semaine ?
4. Qu'est-ce qui vous a manqué ?
5. Recommanderiez-vous le studio à une amie entrepreneure ? Pourquoi ?

## Comment recueillir les bugs
- Demandez-leur d'utiliser **« Écrire à l'agence »** dans le studio, avec une **capture d'écran** (le chat accepte les photos) : quoi, sur quel écran, ce qu'elles attendaient.
- Notez chaque retour dans une liste simple : écran, problème, gravité (bloque / gêne / détail), corrigé ou non.
- En fin de semaine, corrigez d'abord ce qui **bloque**, puis ce qui **gêne** plusieurs personnes. Les détails peuvent attendre.

## Quand ouvrir à tout le monde
- Toutes ont publié au moins un contenu venu du studio, sans aide extérieure.
- Aucun problème « bloquant » ouvert.
- Note moyenne de facilité **≥ 8/10**.
